# Check This Scam — public site

A free, plain-language tool that helps a worried person check whether a
suspicious call, text, or message is a scam — and find the right official place
to verify or report it.

**Live site:** https://penguinz0247.github.io/AmIBeingScammedPublicSite/

## What this is

- A small static website. You answer a few simple yes/no questions about a
  message and get a plain-English read on the warning signs, what to do next,
  and where to report it.
- **Free, private, and no sign-in.** There are no accounts, no cookies, and no
  trackers. Anything you type stays in your browser — nothing is sent anywhere.
- **Independent.** It is not a government site and is not affiliated with, or
  endorsed by, any company or agency named on it. Company and agency names
  appear only to describe who scammers impersonate.
- **General information, not advice.** The tool can't guarantee whether
  something is or isn't a scam, and it never tells you that something is "safe."
  When in doubt, slow down and check with the official source directly.

## About this repository

This is the **public deployment mirror**. It exists only to serve the site on
GitHub Pages:

- The built, ready-to-serve site lives on the **`gh-pages`** branch (that's what
  GitHub Pages publishes). It is generated output — please don't edit it by hand.
- This `main` branch holds just this README.
- The site's source code is maintained separately and published here as a built
  static bundle, so the running front-end is open for anyone to inspect.

## How it's deployed

GitHub Pages serves the `gh-pages` branch at the live URL above
(**Settings → Pages → Deploy from a branch → `gh-pages` / root**). Because this
is a project repository, the site is served from the
`/AmIBeingScammedPublicSite/` sub-path.

## A note on the contact details

Phone numbers and links shown on the site point to official organisations, but
they are **awaiting verification** — always confirm a number or web address on
the official site before acting on it, and trust the official site over this one.
